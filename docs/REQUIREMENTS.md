# 量化交易 Agent — 需求文档 v1.0

> 定稿日期：2026-06-11。本文档是所有开发 session 的唯一需求来源，开工前先读本文件，不要重新讨论需求。

## 1. 项目定位

个人量化研究系统，运行形态为 **Claude Code 项目**：

- **确定性层（不耗 token）**：纯 Python 实现的数据管道、回测引擎、报告生成。可以脱离 LLM 独立运行。
- **Agent 层（耗 token，低频）**：Claude Code skills + 约定，LLM 仅作为"研究助手"——由用户主动发起策略研究、因子设计、回测结果解读、复盘。**LLM 不参与任何实时/自动化交易决策。**

第一期范围：**研究 + 回测**。不含模拟盘、不含实盘、不含自动定时任务。

## 2. 目标市场

| 市场 | 数据源（免费） | 关键约束 |
|------|---------------|----------|
| A股 | akshare（主）/ tushare（备） | T+1、涨跌停板、印花税+佣金、停牌 |
| 美股 | yfinance | 时区（美东）、T+0、拆股/分红复权 |

数据粒度第一期只做**日线**（日线足够支撑中低频策略研究，且数据量小、免费源稳定）。分钟线列为二期可选。

## 3. 功能需求

### 3.1 数据层（纯 Python）
- R1. 拉取并增量更新 A股/美股日线 OHLCV，本地存储为 Parquet（按市场/标的分区）。
- R2. 股票池管理：A股指数成分（如沪深300）、美股自选清单，存为 YAML 配置。
- R3. 数据质量检查脚本：缺口、停牌、异常值、复权一致性，输出文本摘要（供 agent 读摘要而非读原始数据）。

### 3.2 回测层（纯 Python）
- R4. 向量化回测引擎（基于 pandas/numpy，或选型 vectorbt），支持：手续费、滑点、A股 T+1 与涨跌停约束、美股 T+0。
- R5. 标准绩效指标：年化收益、最大回撤、夏普、卡玛、胜率、换手率，与基准（沪深300 / SPY）对比。
- R6. 回测结果落盘：`results/<策略>_<日期>/`，含 metrics.json（< 2KB 摘要，给 agent 读）+ 净值曲线图 PNG + 交易明细 CSV。

### 3.3 策略库（纯 Python）
- R7. 统一策略接口：输入行情 DataFrame → 输出目标仓位/信号 DataFrame。
- R8. 内置基线策略：双均线、动量轮动、均值回归（布林带），作为接口示范和业绩基准。

### 3.4 Agent 层（Claude Code）
- R9. CLAUDE.md：项目约定 + 明确禁令（不读 data/ 下原始数据文件，只读 *_summary.txt / metrics.json）。
- R10. Skills：
  - `/research <想法>`：调研策略思路，输出结构化研究笔记到 docs/research/。
  - `/backtest <策略> [参数]`：运行回测脚本，读取 metrics.json 给出解读。
  - `/review`：对比 results/ 下多次回测，给出改进建议。
- R11. 所有 agent 产出（研究笔记、结论）写入 docs/，形成可追溯的知识库。

## 4. 非功能需求

- N1. **Token 经济性是一级约束**：任何重数据操作必须有"脚本算、agent 读摘要"的形态；详见 PLAN.md 第 4 节。
- N2. Windows 11 本地运行，Python 3.11+，用 uv 管理依赖。
- N3. 全部免费数据源，第一期零现金成本。
- N4. 确定性层有最小单元测试（回测引擎的费用/T+1 逻辑必须有测试）。

## 5. 明确不做（第一期）

- 不接实盘/模拟盘券商接口；不做盘中实时信号；不做定时自动运行的 agent；
- 不基于 claude-code-sourcemap 泄露源码做任何开发（无许可证，法律风险）；
- 不做分钟级及以下高频数据；不做机器学习选股（二期再议）。
