# 回测规范

> 目标：验证策略是否在成本、成交限制和隔夜尾部风险后仍有可重复的正期望。

## 1. 样本与时点

- 市场：沪深A股；主板、创业板、科创板分别报告。
- 排除：ST/*ST、上市不足120个交易日、停复牌异常、当日一字板、次日无法卖出的样本。
- 研究期建议至少覆盖2018年至今；最后20%日期完全留作样本外。
- 所有股票池、板块成员、自由流通市值和公告信息均使用当时可见版本。
- 2019—2021、2022—2024、2025以后分别报告，以识别制度和生态漂移。

## 2. 选择时点

历史忠实版本在14:50计算信号，以14:55—15:00可成交价模拟买入并加入滑点。

2026-07-06后另做“收盘确认 + 盘后固定价格”前向样本：15:00确认，15:05—15:30按收盘价排队成交；未成交必须记录为未成交，不能强制补单。

## 3. 个股信号

默认参数只是首轮起点：

```text
eligible = 非ST & 上市>=120日 & 正常交易
ret_today = price_14_50 / prev_close - 1
size_ok = 30亿 <= 自由流通市值 <= 300亿
liquid = 20日成交额中位数 >= 2亿元
volume_ratio = 当日截至14:50成交额 / 过去20日同时间成交额中位数
turnover = 当日截至14:50成交额 / 自由流通市值
above_vwap = price_14_50 / vwap_14_50 - 1 >= 0.5%
close_strength = (price_14_50 - low_so_far) / (high_so_far - low_so_far)
late_drawdown = price_14_50 / max(price_14_30_to_14_50) - 1
```

入选条件：

- 主板 `3% <= ret_today <= 6%`；20%涨跌幅板块单独寻参，不混池。
- `1.3 <= volume_ratio <= 3`。
- `5% <= turnover <= 15%`，使用自由流通口径。
- `close_strength >= 0.75`，`late_drawdown >= -1.2%`。
- 近20日至少一次真实封住涨停；同时保留触板、炸板和距今天数作为解释变量。
- 热点板块得分满足第4节条件。

## 4. 热点板块定义

只使用14:50前数据。对每个板块计算：

- 板块成分股涨幅中位数排名前3。
- 上涨家数占比不低于60%。
- 至少2只成分股涨幅超过5%。
- 截至14:50成交额相对过去20日同期的增量排名前20%。

板块分类必须固定版本；多概念归属时，至少一个板块满足即可，同时记录概念数量，防止“万能概念股”偏差。

## 5. 组合构建

- 每日候选按“板块得分、尾盘强度、近期涨停质量”预先定义的综合分排序。
- 默认最多5只、等权；单只不超过5%，单一板块合计不超过10%。
- 若候选不足，不强制满仓；剩余为现金。
- 禁止用次日收益优化当日排序权重。

## 6. 退出规则实验

先测三个无主观判断的基准：

- E0：次日开盘全部卖出。
- E1：次日9:45全部卖出。
- E2：次日10:00全部卖出。

再测条件化版本：

| 次日开盘缺口 | 退出规则 |
|---|---|
| `>= +2%` | 开盘卖70%；剩余跌破开盘后VWAP或10:00卖出 |
| `-1% ~ +2%` | 9:45前未创新高或跌破开盘后VWAP卖出，最迟10:00 |
| `-3% ~ -1%` | 9:35前未收复前收盘价则全部卖出 |
| `<= -3%` | 开盘优先退出；若跌停无成交则按真实可成交日顺延 |

条件化版本只有在样本外明显优于E0且规则稳定时才保留。

## 7. 成本与成交

- 买入佣金、卖出佣金、卖出印花税按回测期真实费率或保守上界。
- 滑点至少测试5、10、20、30bp；按成交额参与率增加冲击成本。
- 涨停无法买、跌停无法卖、停牌冻结必须按逐笔/分钟成交状态处理。
- 盘后固定价格交易只用于规则生效后的样本，并使用真实成交标记。

## 8. 消融与对照

按顺序添加条件，检验边际贡献：

1. 同涨幅、同规模随机对照。
2. `+` 流动性与换手。
3. `+` 近期涨停质量。
4. `+` 板块热度。
5. `+` VWAP与尾盘承接。

同时测试删除量比或换手，判断两者是否只是重复过滤。

## 9. 结果指标

- 交易数、成交率、净胜率、平均盈利/亏损、单笔净期望、Profit Factor。
- 次日开盘缺口分布、最大单笔损失、最大回撤、连续亏损次数。
- 每年、板块、涨跌幅制度、牛/熊/震荡、情绪升温/退潮分组。
- 参数扰动热图，不只报告最优点。
- 时间序列交叉验证与样本外bootstrap置信区间。

## 10. 通过标准

建议同时满足：

- 样本外扣费单笔期望大于0，95% bootstrap置信区间下界不显著为负。
- Profit Factor大于1.2，且不是由最赚钱的1%交易贡献全部利润。
- 10—20bp额外滑点下仍保持正期望。
- 关键阈值上下扰动20%后方向不变。
- 至少三个年份为正，熊市/退潮期风险可由预先定义的过滤器控制。

未达到即记录为“策略未获支持”，不得继续通过增加条件追逐样本内最优。
