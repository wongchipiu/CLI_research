# A股热点小盘股尾盘隔夜动量策略

> 建档日期：2026-08-30｜状态：待回测｜市场：A股｜周期：尾盘买入、次日上午卖出
> 本目录保存策略假设、可执行规则和公开资料摘要，不构成投资建议。

## 结论先行

这套方法有合理的微观逻辑：筛选当天已有强度、近期具备涨停辨识度、成交活跃且尾盘仍获承接的热点小盘股，尝试获取次日开盘附近的情绪溢价。

但它目前只是策略假设，不能直接实盘。核心反证来自三点：

1. A股过去盘中赢家在后续盘中可能延续，但同一类股票在隔夜阶段可能显著转弱。
2. A股平均隔夜收益存在负向现象，T+1形成的开盘折价是一个候选解释。
3. 交易成本、滑点和少数隔夜大幅低开，可能吞掉大量小额盈利。

原八项条件中，涨幅、量比、换手、VWAP和尾盘不跳水高度相关，不应被当作五个独立优势。真正值得验证的是三组增量信息：热点板块、历史涨停辨识度、尾盘承接。

## 原始策略

- 当日涨幅 3%—5%。
- 近 20 日有涨停。
- 市值低于 200—300 亿元。
- 量比大于 1。
- 换手率 5%—10%。
- 分时价格站在均价线上。
- 属于当天热点板块。
- 尾盘确认不跳水后买入。
- 次日：高开优先兑现；平开等冲高；低开且不能快速修复则退出。

## 条件审查

| 条件 | 可能捕捉的效应 | 主要缺陷 | 首版量化方式 |
|---|---|---|---|
| 涨幅 3%—5% | 强势但未极端过热 | 不同涨跌幅板块不可混用 | 主板 3%—6%，20%板块单独分组 |
| 近20日涨停 | 股性、注意力、资金记忆 | 触板不等于封板，远近不同 | 记录封板、炸板、距今天数和连板数 |
| 市值 <300亿 | 弹性与散户关注 | 总市值不能代表可交易盘子 | 自由流通市值 30—300亿 |
| 量比 >1 | 当日活跃 | 门槛低，且受早盘量影响 | 成交额/20日同期或全日中位数 1.3—3 |
| 换手 5%—10% | 资金参与充分 | 与量比重叠 | 自由流通换手 5%—15%，做分桶检验 |
| 价格 >VWAP | 当日持仓者偏盈利 | 必须固定观察时点 | 14:50价高于当日VWAP至少0.5% |
| 热点板块 | 注意力与资金共振 | 定义主观、易用未来信息 | 板块涨幅、广度、成交增量的当时排名 |
| 尾盘不跳水 | 尾盘承接 | 肉眼判断不可复现 | 14:30后最大回撤不超过1%—1.2% |

## 可证伪假设

- H1：完整信号的次日开盘净收益显著高于同日涨幅相近的股票。
- H2：“热点板块”在控制个股涨幅、规模和换手后仍有正向增量贡献。
- H3：“近期封板”优于“盘中触板”，且距今越近并非单调越好。
- H4：尾盘承接指标对次日收益有增量解释力，而不只是当日涨幅的替代变量。
- H5：扣除佣金、印花税、买卖价差与冲击成本后，样本外单笔期望仍大于零。
- H6：结果对阈值小幅扰动、不同年份和市场状态稳健，不依赖少数极端盈利日。

若样本外净期望的 bootstrap 置信区间不能高于零，或复杂规则不能胜过“收盘买、次日开盘卖”的简单基准，则策略应判定为未获支持。

## 适用范围

更可能适用：指数非放量下跌、题材主线清晰、板块有上涨广度和梯队、个股流动性充足、没有已知事件风险的交易日。

不适用：ST/退市风险股、新股与复牌股、庄股式低流动性标的、连续高位加速、情绪退潮、重大公告前夕，以及港股或美股等制度不同的市场。

同一题材的多只股票应视为一个相关性仓位。低开止损不能消除隔夜风险，因为亏损可能在开盘前已经发生，甚至遇到跌停无法成交。

## 执行与仓位原则

- 先比较次日开盘、9:45、10:00三种固定退出，再测试高开/平开/低开分支。
- 高开分支、修复时间、VWAP跌破等条件必须完全数字化，禁止回测后主观解释。
- 单笔仓位用压力损失反推：`仓位上限 = 单笔账户风险预算 / 假设隔夜损失`。
- 例：账户风险预算0.5%，主板压力损失10%，则单只仓位上限约5%；20%涨跌幅股票应更低。
- 2026-07-06后沪深A股可在15:05—15:30尝试按收盘价盘后成交，但成交不保证；此前历史样本不得套用该执行方式。

## 当前项目能力边界

当前项目仅有日线 OHLCV，策略接口为 `close DataFrame → 权重 DataFrame`。它不能忠实表达VWAP、尾盘回撤、板块实时热度、开盘后修复或盘后固定价格成交。

因此分两步：先用日线近似检验最弱版本是否有信号，再按 [BACKTEST_SPEC.md](BACKTEST_SPEC.md) 增加分钟数据做忠实回测。日线近似即使盈利，也不能视为原策略已通过验证。
