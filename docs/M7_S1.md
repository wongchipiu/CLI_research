# M7-S1：资金约束与行情可交易性

范围：按 INTEGRATION_PLAN.md 的 S1 修复组合回测，不改变当日收盘成交约定、不实现 S2/S3、不连接行情源或券商。

## 实现设计

1. `load_market_close()` 返回保留 NaN 的原始价格矩阵。引擎从原始价格建立不可交易掩码，只对独立的估值矩阵前填；不得后填上市前的价格。
2. 每日先按上一日的费后实际仓位计算持仓收益，得到调仓前净值和漂移仓位。
3. 目标金额按调仓前净值计算；NaN/涨跌停限制只修改允许成交的数量，不虚构冻结仓位的出售。
4. 先卖出，扣卖出费；可用现金 = 原现金 + 卖出净收入。买入需求超过预算时按比例缩减，且买入金额加买入费不能超过现金。
5. 费后净值 = 调仓前净值 − 买卖费用。输出实际权重以费后净值归一，冻结资产的数量不变；不可为维持权重上限而缩减冻结资产。
6. `costs` 表示费用占上一日净值的比例；`turnover` 为实际成交金额占调仓前净值的比例除以二。第一日也收取费用，`nav` 起始资金为 1，首个输出值可能小于 1。
7. 拒绝非有限决策、非正/无穷价格及无效费率；价格 NaN 表示不可交易，决策缺失继续按原接口视作零目标。

示例：现金为 1、买入费率为 b 时，满仓实际可买金额为 `1/(1+b)`，不是先买 1 再产生负现金；全卖时从出售金额扣除卖出费。

## 验收

- 停牌或跌停导致旧仓卖不出时，不能同时用这笔资金买入新仓。
- 部分冻结、可交易卖出及买入同时发生时，保留冻结数量、按比例分配剩余预算，费后隐含现金非负（浮点容差 1e-12）。
- 价格恢复时按最后已知价格计累计收益；首次价格出现前不得成交或回填未来价格。
- 覆盖零费率、非对称费用、涨跌停、全部/部分冻结及加载器到引擎的合成数据路径。
- 运行工作区完整测试，并在只含拟提交文件的临时导出目录中验证，避免依赖其他未提交成果。
