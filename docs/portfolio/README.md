# 投资诊断知识库

这个目录用于沉淀两类内容：

1. 每日账户诊断记录
2. 稳定复用的方法论、指标口径和决策纪律

目标不是每天都写很长，而是让我们每次诊断都能回答同一组关键问题：账户现在暴露了什么风险、最近市场环境有没有变、今天该不该调整、调整后风险是否真的下降。

## 每天固定流程

1. 记录账户截图或导出券商持仓。
2. 更新当天诊断文档。
3. 复用下面这几个固定口径，不要每天换算法。
4. 如果有新增结论具备长期价值，再沉淀进 `research-notes/`。

## 固定口径

### 账户结构

- 净资产 `Net Liquidation Value`
- 持仓市值 `Market Value`
- 负现金规模
- 维持保证金 / Excess Liquidity
- 总持仓 / 净资产

### 集中度

- 单只仓位占净资产比例
- 前 3 大仓位占净资产比例
- 是否有单一标的超过 `15%`
- 是否有高波动主题合计超过 `30%`

### 风险量化

- 年化波动
- 1 日 95% VaR
- 1 日 95% ES
- 历史最差单日损失
- 与 `SPY` 的相关性和 Beta

### 市场环境

- `SPY`、`QQQ`、相关行业 ETF 距 52 周高点的位置
- 最近 1 个月、3 个月的相对强弱
- 未来 14 天宏观与公司事件

## 决策纪律

- 先判断“账户结构是否安全”，再判断“个股是不是便宜”。
- 不把回本价当成卖出条件。
- 融资账户优先看现金缺口和保证金缓冲。
- 任何加仓动作都要回答：加仓后，组合风险是下降了还是上升了。
- 重大事件前，事件仓必须先定义最大亏损承受范围。
